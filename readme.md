# YLog

## 关于YLog

### 基于C语言的日志库。

## YLog 的优势

1. CMake编译，支持**Windows/Linux**；
2. 支持**控制台带颜色打印**；
3. 支持**日志轮转**；
4. 支持**日志级别过滤**；
5. 宽松的开源协议（**Apache 2.0**）；
6. YLog库**单文件**代码，便于集成；
7. 日志**配置统一**到一个数据结构，便于配置；
